# Agents

This folder contains code for distinct AI agents or agent tooling that we develop. 

While the `.ai/` directory at the root holds meta-configurations, prompts, and global context rules for how AI agents should interact with this repository, the `agents/` folder is designed for the actual source code of those agents.

Each agent should get its own sub-directory here (e.g. `agents/code-reviewer/`, `agents/commit-writer/`).
