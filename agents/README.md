# Agents Workspace

This folder contains distinct AI agents or agent tooling that we develop. 

Each agent resides in its own sub-directory (e.g. `agents/repo-linter/`) and contains a detailed README with instructions on how to build, run, and execute that specific agent.

## Agent's Opinion
*This folder is the "brain trust" of our repository. By decoupling agents into their own isolated directories, we ensure they can possess distinct dependencies (Python, Bash, etc.) without cross-polluting. It's clean and easily scalable.*
